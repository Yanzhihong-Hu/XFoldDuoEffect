# Third-party references

This project contains no Apple models, Apple imagery, or copied iPhone UI assets.

The visual technique was independently implemented for Android after studying public open-source fold-animation experiments, including:

- chuspeeism/iphone-duo — MIT License — fixed front-view projection and progressive blur study.
- lqSky7/iphone-duo-macos-animation — public native macOS progressive-blur study.
- bugwz/MacDuo — public macOS desktop fold study.

No source files from those projects are bundled here. Their repositories remain subject to their own licenses and notices.
